# Lesson 02: Java for robot code

## Purpose

Robot code is different than other Java you may have written before.

Two parts. Do them in this order:

| Part | What | Time |
| --- | --- | --- |
| [Part 1](part-1-java-for-robot-code/) | Read real robot code. | 1 h |
| [Part 2](part-2-elevator-task/) | Build a small elevator program of your own | 1-2 h |

## Prerequisites

- Lesson 01, merged.

## Time box

2-3 hours in total. Split it over two sittings if you want.

## Learning goals

- Split a program into classes that each do one job.
- Read an `enum` that carries behaviour as well as a list of names.
- Say what an `interface` is for, and why one thing might have two of them.
- Write a small program from a spec, split into classes that each do one job, and test it.

## No AI on Part 2

Part 1 is reading. Use whatever helps you understand it.

Part 2 is the one place where the point is what you can write yourself. **No AI tools.** Turn the Copilot extension off in VS Code before you start. 

## Checkoff

Be ready to answer:

- In your elevator, why does the `Elevator` class not print anything?
- What does `this` mean inside an enum's method?
- `IndexerIO` has no logic in it at all. What is it for?
- You add a value to an enum. What do you need to change?
- What could go wrong if `m_indexerMotor` were not `final`?
- Which part of the robot code does your `ElevatorController` match up with?
